# API / 预设独立切换

为 TauriTavern **2.4.0** 制作的前端扩展，操作入口位于「扩展设置 → API / 预设 / 模型独立切换」。读取酒馆中已经保存的连接配置、预设和当前 API 的模型，不需要重新填写密钥。

## 在 TauriTavern 中安装（安卓适用）

1. 打开 TauriTavern 的「扩展」管理界面，点击「安装扩展」。
2. 在 Git 地址栏粘贴：`https://github.com/wiesen857-gif/tauritavern-independent-switcher.git`。
3. 分支或标签留空，选择「安装」或「仅为我安装」。
4. 安装完成后回到扩展设置，找到「API / 预设 / 模型独立切换」。如果没有显示，重启 TauriTavern 并检查扩展管理中是否已启用。

扩展更新可在原扩展管理界面完成。若遇到 `getPresetApplicationPromise` 导出缺失的加载错误，请更新到 **1.0.1** 并重启 TauriTavern。若此前安装过离线 ZIP 版，请先在扩展管理中删除旧的同名扩展，再按上述步骤从 GitHub 安装，避免目录冲突。删除扩展不会删除酒馆原有的 API 配置、预设或聊天记录。

仓库根目录有 `manifest.json`，供 TauriTavern 直接按 Git 地址安装；无需下载 ZIP，也无需访问安卓受限的应用数据目录。

## 使用

- **应用 API 与密钥**：先选 API 配置，再在下方密钥框选择该 API 类型已保存的密钥。默认沿用原配置的密钥设置；若原配置引用已失效，可改选有效密钥后一起应用。从原连接管理器读取 API 类型、协议、地址、模型和反代，跳过捆绑的生成预设、正则预设、指令模板和预填充。聊天补全的采样参数和未保存的提示词设置保持不变。
- **密钥选择**：位于 API 配置和模型之间，只显示密钥名称，不读取或展示密钥内容。选择仅用于当前扩展面板中的切换，不改写原配置，也不另存密钥。更换目标 API 配置时会重置选择，防止沿用上一个配置的临时密钥。
- **仅切换预设**：读取当前补全类型的预设，使用酒馆原加载流程应用提示词和采样参数，同时跳过聊天补全预设中的连接字段。当前 API、地址、模型和密钥引用保留。预设附带的正则、脚本等仍由酒馆及相关扩展按原规则处理。
- **仅切换模型**：模型选项位于 API 配置下方，显示当前模型，从当前 API 已加载的模型列表选择新模型。只调用酒馆原生模型切换功能，不重新应用连接配置或预设。切换 API 后会自动更新模型列表；若列表为空，请先在原 API 面板加载模型，再点刷新。
- **刷新 API、模型和预设**：重新读取配置、密钥和预设，并通过原生连接按钮重新请求当前连接的模型列表；模型返回后自动更新。连接、密钥与模型状态变化时也会自动更新列表。

下拉框选好后点击对应按钮才会应用。API 按钮完成后会发起原生连接检查，实际是否连通请看原 API 面板；“已应用”不等于远程服务已连通。

操作结果和错误显示在刚点击的按钮下方。若原配置提示密钥不存在，选择 API 后在密钥框改选有效条目，再点击“应用 API 与密钥”。

## 行为边界

- 独立切换仅在本扩展面板生效；原连接管理器仍会按原规则应用整套配置。
- 本扩展不重写已保存的连接配置或预设，不另存一套配置库。切换后的当前设置由酒馆原生保存机制保存。
- 聊天补全与文本补全使用不同的预设结构。跨补全类型的配置会置灰，需先在原 API 面板切换类型；同一补全类型内可以独立切换。
- 普通连接配置没有保存或主动排除的字段，保持原生“未提供则保留”的含义；模型配置则遵循原生语义，清除未保存的地址与反代。
- 这里只应用连接配置实际保存的连接字段；不会从捆绑预设中另外提取自定义请求头或额外请求体。若某个接口依赖这些参数，请先在原 API 面板设置正确。
- 生成中禁止切换。中途应用失败会停止后续字段与自动重连，并显示错误；已应用的部分连接字段可能保留，请检查原 API 面板后重新选择有效配置。
- 其他扩展若在预设事件中自行切换连接或执行脚本，仍可能改变连接；本扩展不接管其他扩展的行为。
- 模型切换会执行酒馆原生模型变更处理；酒馆可能根据模型限制调整当前上下文长度或采样参数，但不会改写已保存的预设。
